## Where Solicamp stands

Solicamp is early but working. Compile, deploy, call, multi-file workspaces and rooms run inside Basecamp.

| Feature | State |
|---|---|
| Compile, deploy, call, Interact panel | Working |
| Files and folders, autosave, drag and drop | Working |
| Rooms (separate local chains) | Working |
| Publish to Bedrock (opt-in) | Built. Tested outside Basecamp. Wallet balance reading is being refined. |
| Shared rooms over Logos Messaging | Built and tested in memory. A two-window test in Basecamp is next. |
| Release to the module catalog (Mac and Linux) | In progress |
